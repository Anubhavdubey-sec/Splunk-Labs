# Splunk Labs

A hands-on Splunk portfolio demonstrating log analysis, SPL query development, threat hunting, detection engineering, alert investigation, and security visualization.

## Objective

This repository demonstrates my ability to:

- Analyze security logs using Splunk
- Write SPL queries
- Investigate suspicious activity
- Correlate events
- Perform threat hunting
- Develop security detections
- Analyze authentication activity
- Investigate web and network logs
- Build security dashboards
- Document investigation findings
