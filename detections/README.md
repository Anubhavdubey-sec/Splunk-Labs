# Splunk Detection Labs

This directory contains Splunk-based security detections designed to identify suspicious and potentially malicious activity.

## Objective

These labs demonstrate the ability to translate attacker behavior and security hypotheses into practical SPL-based detections.

## Detection Workflow

```text
Threat Behavior
      ↓
Security Hypothesis
      ↓
Required Telemetry
      ↓
SPL Detection Logic
      ↓
Testing
      ↓
False Positive Analysis
      ↓
Tuning
      ↓
Alert
      ↓
Investigation
